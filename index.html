Relational Database Schema (Primary Key & Foreign Key Design)

Two normalized tables linked via a Foreign Key constraint (contacts.group_id → contact_groups.group_id)

Primary Key (PK) Foreign Key (FK)
TABLE: contact_groups Parent Table
  • group_id (PK) VARCHAR(10) NOT NULL
  • group_name VARCHAR(50) NOT NULL
  • description VARCHAR(150)
TABLE: contacts Child Table
  • contact_id (PK) VARCHAR(20) NOT NULL
  • full_name / phone / email VARCHAR(100) / UNIQUE
  • group_id (FK) REFERENCES contact_groups(group_id)
  • city / priority_score / is_favorite VARCHAR / INT / BOOLEAN
